Claude Code setup checklist

Reel ka free guide. Steps official docs se liye hain (22 Nov 2026 ko check kiye).

STEP 1

Claude account chahiye

Zyada tar surfaces par Claude subscription ya Anthropic Console account lagta hai. Pehle account ban lo.

STEP 2

Install karo

Windows PowerShell
irm https://claude.ai/install.ps1 | iex
macOS, Linux, WSL
curl -fsSL https://claude.ai/install.sh | bash

Install ke time koi progress nahi dikhta. Wait karo.

STEP 3

Check karo

Naya terminal window kholo aur chalao:

claude --version

Version number aaya, toh install theek hai.

STEP 4

Apne project mein chalao

cd your-project
claude

Pehli baar login ka prompt aata hai.

STEP 5

"claude not found" aaye toh

Install folder PATH mein nahi hai. Docs ka "Fix your PATH" section dekho.

Source: code.claude.com/docs/en/overview. Yeh independent guide hai, Anthropic ka official page nahi. Commands badal sakte hain, isliye docs se verify karo.
